# 小鱼号AI共创社区

一个可本地运行、可自行部署的公司内部 AI 分享与讨论社区。经验、项目、技能包、提示词和独立论坛并行，既能沉淀成果，也能随时提问、讨论、反馈和闲聊。React + TypeScript 前端，Fastify 模块化单体服务，正式环境 PostgreSQL，开发环境使用文件持久化的 PGlite。没有接入外部 AI 推理或真实内容审核服务。

## 快速开始

本仓库包含网页端、手机网页端、微信小程序及共用服务端：

| 部分 | 代码位置 | 说明 |
| --- | --- | --- |
| 网页端 | `src/` | React + TypeScript，包含管理后台 |
| 手机网页端 | `src/mobile/` | 复用网页账号、内容和业务接口，见 [手机端维护说明](docs/MOBILE.md) |
| 微信小程序 | `wechat/miniprogram/` | 微信原生页面，使用微信开发者工具导入 `wechat/` |
| 微信云函数 | `wechat/cloudfunctions/` | 微信身份与社区接口桥接，见 [小程序说明](wechat/README.md) |
| 共用服务端 | `server/`、`migrations/` | 账号、内容、权限、审核及数据库迁移 |

仓库只保存代码、品牌素材和配置示例。运行配置、密钥、用户数据库及私有附件不随代码上传；部署时保留服务器已有数据，云函数密钥通过环境变量配置。

维护或部署更新前，请先阅读 [维护与上线约束](docs/MAINTENANCE.md)，保留已上线审核方式和真实数据。

需要 Node.js 22.12+ 和 npm。首次运行按下列步骤初始化空开发库；已有数据库直接启动，不重复初始化。本轮手机布局开发目录只复制源码，原开发数据仍留在原目录。

```bash
npm ci
cp .env.example .env
# 可选：本地演示将 MODERATION_PROVIDER 改为 development。
# 默认 none 会进入人工复核。
npm run seed
npm run dev
```

在 Windows PowerShell 使用 `Copy-Item .env.example .env` 替代 cp。已有数据库不重复运行 seed；它只允许空开发库，不能用于 production。

打开 **http://127.0.0.1:3000**。随机初始密码与开发邀请码保存在 `outputs/本地访问说明.txt`，不写入源码。默认种子账号：admin、lin.xia、chen.yu、zhou.ning。内容与互动均为明确标注的开发示例；新增操作真实写入数据库。

Windows 本地预览：双击 `outputs/打开社区预览.cmd`，或运行 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/start-preview.ps1`。启动器会检查现有服务，必要时在后台启动并打开论坛；不会重置数据库。电脑重启后可再次运行。该入口使用本地开发数据库与开发审核模拟器，仅监听本机地址。

`npm run dev` 先编译服务端，再启动 API 和 Vite 前端开发服务。前端支持热更新；修改服务端需要重启命令。编译式入口兼容当前 Windows 受限环境，避免 tsx 调用系统用户信息时的兼容问题。

### 生产构建在本地预览

```powershell
npm run build
$env:SERVE_BUILD='true'
$env:MODERATION_PROVIDER='development'
npm start
```

这仍然是本地开发模式，不要将该启动方式暴露公网。正式生产设置 NODE_ENV=production、DATABASE_URL、HTTPS APP_ORIGIN，且不得使用 development 审核。

- 首页与导航突出讨论入口，经验、项目、技能包和提示词详情均可查看、发起关联话题；资源原有评论继续可用。
- 关注话题后收到已审核新回复通知；阅读人数按用户去重，未读与最近动态使用审核通过时间，避免延迟审核漏掉新回复。
- 邀请注册、账号密码登录、退出、资料修改、自定义头像、密码修改和管理员一次性密码重置。
- 草稿箱支持删除，已发布文章的新草稿可单独丢弃；管理员可删除员工账号并撤销登录与接口凭据，历史文章和互动保留。
- 个人中心“AI 接入”：个人密钥、通用 HTTPS 投稿和本人投稿状态查询；归属本人，按账号审核设置发布，支持幂等重试。见 [接入说明](docs/AI-POSTING-API.md) 和 [OpenAPI](public/integrations/openapi.json)。
- 邀请码到期/次数/默认部门/撤销/使用记录，事务行锁避免并发超额注册。
- 普通成员、部门与分类范围版主、超级管理员。部门与角色只能由管理员修改；停用撤销全部会话。
- 经验、项目、Skill、提示词四种发布表单。富文本、代码、上传进度、草稿自动保存、预览、状态与失败反馈、下架与删除确认。
- 不可变修订，已审核版本与待审版本分开，项目和 Skill 历史版本保留原有互动。乐观并发检测避免覆盖其他浏览器的修改。
- 私有图片与附件存储、真实类型检查、图片重编码、受限 ZIP 解析、存储额度、文件扫描/隔离与正文附件统一审核、授权下载和版本记录。
- 首页轮播、分类入口、精选、最新、资源推荐；类型/分类/标签筛选、中文关键词搜索、分页与点赞/浏览/下载榜。浏览使用实际访问事件，按北京时间每天去重并排除作者；贡献周榜独立保留。
- 点赞、收藏、评论、回复、举报、通知、我的发布/草稿/待审/退回/收藏/下载、作者主页。
- 管理工作台：成员、范围授权、邀请码、部门、分类、标签、工具、内容精选/置顶/下架、审核队列/记录/重试、规则、评论、举报、附件检查、轮播编辑、站点名称/图片或文字 Logo/简介/上传配置、公告、操作日志。
- 审核队列支持勾选、全选本页、批量通过和退回；通过无需原因并同步通过关联的待检查文件，退回需填写原因。逐项处理与反馈，权限、最新修订、已阻止文件和禁止发布规则继续检查。
- 响应式桌面与手机界面、键盘焦点、表单标签、加载/空数据/错误/无权限反馈。

邀请注册说明姓名用途、账号格式与不可修改、确认密码及邀请码获取方式；所属部门由邀请码分配。注册、修改和重置密码统一为 6–20 位，不强制字母数字组合，不接受全空格；已有密码不变。

登录需填写 4 位图片验证码，不区分大小写，2 分钟有效，点击可换图。每次校验只能使用一次，验证码或密码错误后自动换图。接口只返回 PNG、随机标识和有效期；数据库仅保存 HMAC 校验摘要和浏览器绑定摘要，答案不写日志，不提供后台明文查询。登录继续保留原有请求限流；历史超过 20 位的密码仍可登录并修改。

部门按提供的组织截图排序：总经办、海外及大客户服务中心、品牌中心、设计部、供应链中心、营运中心、财务部、人力行政部、招商中心、外卖运营部、工程部、研发中心、团购运营。迁移 `009_company_departments.sql` 将原演示部门对应重命名并保留 ID，成员、邀请码、内容及版主权限关系继续有效；其他已存在的自定义部门不删除。

Logo 支持文字、Emoji 与 PNG/JPEG/WebP 图片；管理员上传后直接更新并记录操作日志，无需内容审核理由，登录后通过鉴权接口展示。正文/封面/轮播支持内容附件。当前默认使用私有磁盘存储，`PrivateStorage` 接口预留 S3 实现，未宣称已接入对象存储。

默认品牌使用用户提供的原生透明矢量 LOGO，小鱼人物融入首页图片轮播和登录页。轮播下方立即左右分栏：左侧讨论、分类与内容统一宽度，右侧发布分享与贡献榜对齐；资源详情的正文、关联讨论和评论使用同一主列。顶部四类资源导航按当前类型单独选中。

### 图片轮播、红色品牌与 AI 图标

运行时品牌素材使用 `public/brand/optimized/` 下的 WebP 与轻量按钮 SVG；原始素材继续保留。`npm run assets:optimize` 可重新生成，生产构建自动执行。文件名包含内容哈希，浏览器长期缓存并在素材变化时自动换址；移动端轮播使用较小图片，当前图片优先，下一张延后低优先级预载。私有图片、头像及上传 Logo 仅在重新校验登录、权限与文件状态后使用 ETag 返回 304，不进入公共缓存。本机实测首页首屏品牌图片由约 11.6 MB 降至 0.56 MB（约减少 95%），这表示传输量变化，不是网络耗时承诺。

参考指定的阿里云千问 AI 活动页的圆角卡片、胶囊按钮和立体插画，以原 LOGO 的 #D8292F 红色配暖白、浅珊瑚粉。LOGO 在上、站名在下，标题沿用参考页的 PingFang SC / Microsoft YaHei 粗体字体栈。论坛、导航、筛选、发布、评论、个人资料和登录界面共用这套视觉样式。

首页使用三张以最初的小鱼透明 PNG 为唯一人物参考、通过内置 image_gen 一次重新生成的 3:1 横幅，分别对应经验分享、项目共创与技能资源。左侧为干净的浅桃粉留白，搭配深红标题；原小鱼本身保留蓝色。当前图片和完整提示词保存在 `public/brand/banners-clean/`，不依赖外部生成服务即可正常显示。桌面标题、说明和按钮整体垂直居中；移动端保留文字与人物分区。

分类、导航操作、点赞收藏、附件、富文本工具栏和管理功能使用同系列 AI 图标。72 枚图标按四张透明图集组织，另外四款胶囊底图用于按钮状态，素材与提示词在 `public/brand/ui-red/`。`src/icons.tsx` 用 SVG 视口显示单个图标；文字、焦点、点击、禁用和权限仍由真实 HTML 控件管理。

胶囊按钮使用 SVG 单格视图配合 CSS border-image 分段延展，端部始终按按钮高度等比缩放，中间随宽度扩展，避免宽按钮变成扁椭圆。PNG 原图不改动；`node scripts/build-button-skins.mjs` 可重建 `button-skins.svg`。管理后台字体独立增加一级，共享数据请求按 URL 隔离响应，管理标签切换不会把列表内容误当设置表单。

- 自动轮播间隔 6.5 秒；支持上一张、下一张、圆点、暂停/播放、键盘方向键和手机左右滑动。
- 悬停暂停、移出恢复；键盘进入或手动选择后暂停；遵守系统减少动态效果偏好，后台标签页不自动切换。
- 后台“首页轮播”的标题、跳转、顺序、定时与停用继续生效；配置了图片时优先展示该鉴权图片，否则按资源类型显示默认横幅，图片失败时自动回退。
- 手机端将文字和插画分区展示；无配置时显示三张通用入口，不显示受限资源内容。全新开发示例库包含三张可编辑轮播，已有配置不被迁移覆盖。

### 自定义头像

在“个人中心 → 资料与密码”选择图片后，可拖动、缩放、方向键微调或重置方形裁剪区，再保存头像；手机支持触摸拖动。可取消选择或移除头像。支持 PNG/JPEG/WebP，最大 5 MB / 20 MP，服务端校验原图、自动方向和裁剪坐标，按选区重编码为 256px WebP。保存后页头、作者主页、帖子和评论使用同一头像版本。

头像通过登录鉴权读取，不存入公共目录。所有环境保存后立即生效，不进入内容审核；姓名和简介同样直接更新。保留文件格式、大小、像素限制及已配置的恶意文件扫描。启动自动执行 `007_profile_without_review.sql`，将旧待审头像设为当前头像并清理待审状态，保留历史审计。内容审核仅处理帖子、文章等发布内容与评论回复。

## 富文本编辑与评论

评论、论坛回复、论坛发帖和四类资源正文统一使用所见即所得编辑器。文字格式、图片和表情直接显示在编辑区，不再输入或切换到 Markdown 源码。工具栏提供段落/标题、加粗、斜体、下划线、删除线、清除格式、列表/任务列表、引用、代码、链接、表格、图片、表情、附件、撤销重做及全屏。

编辑器按需加载。历史 Markdown 内容可直接打开、继续编辑和保存，不需要迁移正文。支持粘贴常见富文本的基础格式；不提供 Word 全版式、字体字号、分页或 DOCX 编辑能力。底层继续使用可审计的 Markdown 存储，表格换行和少量无属性行内格式标签由白名单转换为安全节点。

- 图片支持选择、剪贴板粘贴与拖放；可多文件逐个上传，显示进度并移除未提交素材。
- 表情面板包含 72 个常用 Emoji 与 12 个项目自有图形表情包；也可通过图片按钮上传自定义 GIF。
- 评论最多 10 个素材，可仅发送图片或附件；存储正文（含格式标记与素材地址）限制 5,000 字符，资源和论坛正文限制 150,000 字符；工具栏下方显示可见文字字数，达到容量上限时保留已有内容并提示。
- 默认附件类型包括 TXT/MD/JSON/CSV/ZIP 与 PDF/DOCX/XLSX/PPTX。普通账号的 PDF/Office 与正文一并审核通过后才可公开下载；免审账号的附件同步免审，保留格式及已明确拦截文件限制。
- 新增 `004_comment_media.sql` 会在启动时迁移。图片、文件跟随评论的审核和权限，不能通过直链读取他人待审素材。

## 安全与统计约定

权限以数据库中的当前账号状态、部门、内容范围、修订范围和版主授权为准。所有 API、历史、评论、通知、搜索、推荐和文件接口重新判权，无内容缓存或公共附件目录。无权限统一返回不存在，避免泄露标题或数量。

关联论坛话题的可见范围始终与原资源当前访问权限取交集。原资源收紧部门范围、下架或删除后，无权用户（包括话题作者）不能再通过话题正文、附件、楼层、搜索、收藏、通知或历史修订访问。论坛版块复用内容分类，管理员在“内容分类 / 论坛版块”中维护。锁帖会在服务器评论入口强制检查。

已有实例升级时先备份数据库与附件，替换源码、运行 `npm ci` 和 `npm run build`，重启服务会顺序执行 `002_forum.sql`、`003_forum_activity.sql`，保留已有内容。只升级结构，不给生产库添加示例帖。已有本地开发示例库可在停止服务后执行 `node dist/server/cli.js seed-forum` 补充六个示例话题；该命令幂等且禁止生产/外部数据库。全新 `npm run seed` 会同时初始化资源和论坛示例。

密码使用 scrypt（N=32768，r=8，p=1，随机盐），会话使用随机 256 位令牌且数据库只存 SHA-256 摘要。Cookie HttpOnly、SameSite=Lax，production 必须 Secure。写操作验证 Origin 与 CSRF；登录、注册限流。SQL 参数绑定、Zod 校验、不启用任意 HTML 渲染；仅将无属性的 u/strong/em/s/del 和 br 格式标签转换为安全节点，事件、脚本和其他 HTML 保持不可执行。正文图片仅允许站内鉴权地址与内置表情白名单。

点赞每人每内容只有一条有效关系，首次事件时间不会因取消再赞被刷新。周/月榜分别取近 7/30 天事件；取消后的点赞不再计分。下载以鉴权通过且成功发送文件的 HTTP 响应记录，不能解释为用户已在本机保存完成。榜单按同人同内容上海时区每日最多一次去重，作者自己不计分；版本级原始记录保留。外部链接只计跳转。榜单与收藏均再次过滤当前权限。

## 审核配置

管理员在“管理后台 → 成员与权限 → 权限与部门”打开某个账号的“发布免审”并保存。默认关闭；开启后，该账号新提交的文章、项目、技能包、提示词、论坛帖子和评论回复直接发布，个人接口投稿同样生效。关闭后新提交恢复审核，已有待审内容不自动放行。修改和发布均记录操作日志，普通成员不能自行开启。免审覆盖正文、图片及附件，跳过内容规则与人工审核；权限、格式、大小和额度仍校验，已明确阻止的文件不能放行。普通账号在审核队列中一并审核正文、图片和附件，不再需要到文件管理分别审批。

需审核账号使用预置 19 条规则：6 条明确辱骂短语直接退回，13 条疑似辱骂、暴力、恐怖主义、政变、仇恨相关短语交人工复核。实际攻击或煽动不得通过，对所有国家一致；正常新闻、研究、批评及时政讨论可发。规则可在后台管理；短语匹配不能替代语义审核，需审核账号未命中规则的生产投稿仍须人工批准。

| 配置                              | 行为                                         |
| --------------------------------- | -------------------------------------------- |
| `MODERATION_PROVIDER=none`        | 所有生产内容/评论待人工复核                  |
| `MODERATION_PROVIDER=development` | 仅开发模拟，production 拒绝启动              |
| `CLAMAV_HOST` / `CLAMAV_PORT`     | 可选恶意文件扫描；普通账号未扫描文件随正文审核，免审账号直接可用，已检出恶意仍阻止 |

开发测试标记：`[dev:reject]` 退回，`[dev:review]` 人工复核，`[dev:timeout]` 异常重试。任何模型输出、上传的脚本与技能包都不在服务器执行。

供应商适配和覆盖边界见 [审核接入说明](docs/MODERATION.md)。尚未选择或集成真实供应商，因此没有虚构第三方审核接口或识别能力。

## 生产初始化、部署与恢复

本地无示例数据时，可通过临时环境变量 `ADMIN_USERNAME`、`ADMIN_PASSWORD` 运行 `npm run admin:init`。密码 6–20 位，无需字母数字组合，不能全为空格；初始化后删除临时环境变量，已有管理员时拒绝重复初始化。

容器部署使用 `node dist/server/cli.js admin`。完整流程、Caddy HTTPS、持久化卷、备份与恢复脚本见 [部署说明](docs/DEPLOYMENT.md)。需要提供服务器和域名信息后才能实际部署；当前未连接美国服务器，也未上线。
