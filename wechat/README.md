# 多端论坛微信小程序

在微信开发者工具导入本目录。小程序原生页面在 `miniprogram/`，微信身份云函数在 `cloudfunctions/communityIdentity/`；首页、讨论、个人页和发布流程沿用手机网页的红白主题与布局。

[仓库首页](../README.md) · [开发与操作规范](../CONTRIBUTING.md) · [手机网页基准](../docs/MOBILE.md) · [维护与上线约束](../docs/MAINTENANCE.md)

## 使用状态

仓库提供通用小程序源码。AppID 使用游客占位值，云环境为空，不默认连接任何实际社区。本轮没有上传开发版、提交审核或正式发布。配置真实 AppID 和云环境后，在微信开发者工具编译、真机验收，再分别记录上传与发布状态。

## 代码入口

| 位置 | 职责 |
| --- | --- |
| `miniprogram/pages/` | 首页、讨论、详情、发布、消息、个人页、榜单 |
| `miniprogram/components/` | 内容卡片、加载与错误状态、私有图片、正文展示 |
| `miniprogram/custom-tab-bar/` | 首页、讨论、发布、消息、我的五入口 |
| `miniprogram/lib/api.js` | 云函数调用、登录状态与社区接口 |
| `cloudfunctions/communityIdentity/` | 微信身份、手机号能力和服务端接口桥接 |
| `../server/miniprogram.ts` | 账号绑定、小程序会话及服务端访问边界 |

修改小程序使用 `area:wechat` 标签；同时改动共用服务端时加 `area:backend`，涉及云函数配置或上线时加 `type:deployment`。

## 登录与数据

网页管理员可在「成员与权限」为成员填写手机号。成员在小程序授权微信手机号后可进入对应的原账号，也可使用社区账号密码登录。新成员使用同一套邀请码注册。已经配对的微信可直接登录，社区网站的 `/wechat` 页面继续提供配对及解除绑定。

小程序通过 `wx.cloud.callFunction` 调用 `communityIdentity`，云函数通过 HTTPS 访问社区服务器上允许小程序使用的接口。网页与小程序共用账号、内容、部门权限和审核记录。小程序单个附件上限为 700 KiB，更大的附件可在网页处理。

小程序内支持搜索、资源与论坛、附件预览、点赞收藏、评论回复、消息、榜单、个人贡献、草稿与发布。编辑器输入 Markdown。后台审核、成员管理和 ZIP 下载继续通过网页操作。

## 部署

1. 在 `project.config.json` 填写自己的 AppID；在 `miniprogram/config.js` 填写社区 HTTPS 域名与云环境 ID。游客 AppID 仅作源码占位，不支持云开发登录。不要把原实例配置复制到无关项目。
2. 在云函数运行环境设置 `COMMUNITY_ORIGIN=https://forum.example.com`（替换为自己的 HTTPS 根域名）、`MINIPROGRAM_APP_ID` 与 `MINIPROGRAM_BRIDGE_SECRET`。社区服务器配置相同的后两项。密钥仅在服务器与云函数环境中保存，不能放进小程序或公开记录。函数超时建议 10 秒。
3. 使用微信开发者工具将 `communityIdentity` 上传并部署到上一步指定环境，安装其云端依赖。已有实例先新增 `COMMUNITY_ORIGIN` 再更新云函数，否则会返回配置提示。只填写 HTTPS 根地址，不带路径、查询参数或用户名密码；上游地址不能由客户端传入。
4. 核对微信手机号授权资质及隐私指引，在真机验证登录、列表、讨论、附件与部门权限；使用隔离账号验证发布和复核。网页与小程序应显示同一批真实数据，不导入生产账号到演示库。
5. 按微信公众平台要求核对主体、备案、隐私指引及服务类目。上传开发版、体验版、提审和审核后发布分别记录，以平台实际状态为准。仅在获得发布授权后执行部署或上传。

### 回退

关闭小程序接入时，可保留迁移后的结构。停止社区服务，撤销 `sessions` 中 `mini_app_id IS NOT NULL` 的会话，恢复备份中的原配置，并切回原发布目录。撤销小程序会话必须先于切回不支持小程序会话隔离的旧版，否则旧代码无法区分该类凭据。恢复服务后检查网站和 HTTPS。避免用旧数据库覆盖此后新增的线上数据。
