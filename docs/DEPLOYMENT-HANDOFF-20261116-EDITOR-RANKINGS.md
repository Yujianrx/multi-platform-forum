# 编辑与首页入口修复上线交接

站点：https://ai.yujianrx.top。上一版本 20261116-v6。沿用用户已授权的原服务器备份、隔离验证、切换和 HTTPS 验收流程；保留所有现有账号、文章、附件、会话、密钥、审核设置和积分荣誉。

## 本次修复

1. 删除草稿入口补齐至个人“我的发布”、草稿箱、编辑页、草稿详情及管理员后台内容列表。仅作者/管理员可操作，待审或已发布正文没有草稿删除按钮。公开文章的新草稿只删除未发布修订。
2. 首页在本周贡献榜下新增独立的社区人气榜卡片，点赞/浏览、近 7 天/近 30 天/累计切换，真实前 5 条及数量；完整榜单、下载榜和贡献榜均保留。
3. 编辑页操作栏在导航下吸附，按钮为“保存草稿”“发布内容”；发布直接走原提交审核/账号免审流程；可选预览保留在步骤栏。
4. 站内导航、顶部发布、搜索和浏览器返回由路由统一拦截。弹窗支持继续编辑、保存后离开、直接离开；保存失败不离开，保存/上传进行中不能离开。刷新和关闭有未保存内容时使用浏览器原生提示。

## 发布边界

- 只有前端与文档/测试变化；server/、migrations/001–014、package.json、package-lock.json 保持 v6 字节不变。**没有新数据库迁移，不运行 seed。**
- React Router 使用既有版本的 createBrowserRouter / RouterProvider 支持 useBlocker；未新增依赖。
- 保留 v6 所有删除、浏览去重、审核、免审、附件检查、积分和勋章逻辑。无新演示账号或内容。
- 本地源码包、outputs/编辑与榜单-变更清单.json、outputs/编辑与榜单-保留项校验.json 为交付证据；实际测试见 docs/VERIFICATION.md 最新一节。

## 验收要点

- 在隔离库使用成员与管理员检查个人列表和编辑页删除入口，管理员后台检查作者草稿；不要删除正式站真实账号、文章或草稿。
- 首页需要看到真正的排行榜条目和数量，不能仅检查跳转链接；切换点赞、浏览、周期和完整榜单。
- 桌面及手机滚至编辑页底部，检查两按钮仍在视口；误点顶部发布弹出离开确认，取消后文字不丢失；保存失败留在原页；保存后离开再打开草稿可恢复。
- 直接发布仍按现有审核设置处理，普通批准不自动计案例/资源积分。
- 生产验收不提交真实文章、不修改真实审核任务。需要测试写入时使用隔离数据库。
- 正式切换前备份 DB、私有文件和配置，保存摘要；切换前后数据、文件、审核规则及免审标志核对一致，检查静态文件版本和 HTTPS，保留上一版可回退代码。其他站点不受影响。
