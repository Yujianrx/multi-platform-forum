# Mobile Visual Preview Plan

**Goal:** 用可点击预览展示已确认的手机端页面结构。
**Architecture:** 独立的自包含视觉稿，所有状态和内容留在本地预览；不调用网站接口。
**Tech Stack:** HTML/CSS、少量本地交互、品牌素材、既有 Lucide 图标。
**Spec:** docs/plans/2026-11-16-mobile-visual-design.md

## Constraints

- 首页默认最新，底部第二项为讨论。
- 不改业务代码、不部署、不读取真实账号和内容数据。
- 保留原 LOGO；图片保持比例，文字可读；示例数据明确为视觉演示。

## Tasks

- [x] 设计首页双列卡片、单列论坛、个人主页及共同导航。
- [x] 接入品牌素材，提供页面切换、频道及发布面板预览。
- [x] 检查 390px、320px 和更窄的 288px 容器，修正遮挡与溢出。
- [x] 输出可交互视觉稿；下一步等待视觉反馈。

## Validation

独立视觉稿保存在本对话可视化目录，约 400 KB；所有品牌素材内嵌，不调用网站接口。浏览器检查覆盖主导航、频道、内容分类、轮播切换、搜索、发布面板、勋章详情、草稿标签与榜单分类。没有脚本异常、破图或横向溢出。网页和真实业务数据未修改。
