# Rich Text Editor Implementation Plan

**Goal:** 所有正文和回复编辑区直接展示文字格式、图片和表情。

**Architecture:** Tiptap 文档模型与现有 Markdown 存储双向转换；共用 MediaComposer，保持 API 和数据库不变。

**Tech Stack:** React / TypeScript / Tiptap 3.34.0 / Fastify / Playwright。

**Spec:** docs/plans/2026-11-14-rich-text-design.md

## Global Constraints

- 保留现有内容、附件权限、审核、草稿与版本数据。
- 评论最多 5,000 序列化字符、10 个附件；正文最多 150,000 字符、30 个附件。
- 站内图片路径和表情白名单保持一致，不加载外部图片。
- 避免不必要的辅助标签与说明，让布局本身发挥解释作用。
- 本会话直接执行，用户已授权，不额外委派或审批；无 Git 仓库。

## Review Focus

- 历史 GFM 表格、任务列表、换行、代码和图片保存后不丢失。
- 工具栏或表情面板获得焦点后，选区与撤销仍正确。
- 粘贴 HTML、外部图片、脚本和危险链接不进入可执行展示。
- 中文组合输入和达到长度上限时，正文保持可恢复。
- 图片异步上传、外部草稿更新、评论成功清空不覆盖新编辑。
