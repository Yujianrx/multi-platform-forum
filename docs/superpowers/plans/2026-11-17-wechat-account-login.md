# 小程序登录与注册

- 在网页「成员与权限」增加可选手机号。保存时统一号码格式，限制重复，只向有成员管理权限的管理员返回完整号码。
- 小程序支持微信手机号、账号密码和邀请码注册。微信云函数换取已验证手机号后匹配原账号，复用现有微信身份绑定和普通账号权限。账号密码和注册沿用网站的验证码、邀请与密码规则。
- 保留已有微信绑定和配对码入口。管理员变更号码时撤销依靠该号码建立的绑定及其小程序会话。未录入号码的成员仍可使用账号密码。
- 测试真实微信绑定、输入无法绕过验证、重复号码、旧账号归属、邀请码、账号停用和变更手机号。服务器升级前备份并在 PostgreSQL 隔离副本验收。
- 小程序调用已关联的微信云函数，由云函数通过 HTTPS 转发已授权的社区接口。小程序单个附件上限为 700 KiB，大于该限制的文件仍可在网页处理。
- 在微信后台核对手机号接口资质与隐私声明，再做真机验收。
