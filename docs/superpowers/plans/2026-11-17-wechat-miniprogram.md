# 论坛微信小程序实施计划

**目标**　在微信开发者工具预览原生小程序，用既有账号访问同一套线上社区数据。

**架构**　微信云函数从可信运行时取得 AppID 与 OpenID。社区网页用现有会话和 CSRF 机制确认短期配对码。Fastify 将已绑定身份换成限于小程序业务接口的短期会话。资源、论坛、互动、审核、积分与私有文件继续由现有 PostgreSQL 和文件服务管理。

- [x] 实现 `015_wechat_miniprogram.sql`、云身份桥接和网页 `/wechat`，验证配对竞争、失效、解绑及现有账号权限。
- [x] 在 `wechat/` 实现微信云函数及原生页面，复用查询、内容、论坛、消息、贡献、草稿提交及私有文件接口。沿用社区红色品牌与等高双列。
- [x] 验证编译和隔离数据联调，涵盖受限内容、归属、附件、免审、点赞与回复。
- [x] 核实 AppID 和云环境，在真实 PostgreSQL 副本演练，备份后追加微信绑定结构，核对既有记录和文件摘要并切换。
- [x] 生成内部预览码，部署微信云函数并上传 0.1.0 开发版。
- [ ] 完成云函数运行配置、合法域名核对、真机绑定与访问验证，随后核对提审要求和正式发布状态。

直接读写同一服务可以即时反映权限变化。全量复制到云数据库需要维护双向写入、删除和权限回收；网页嵌入会增加业务域名和登录适配依赖。本项目采用原生页面加云身份桥接。
