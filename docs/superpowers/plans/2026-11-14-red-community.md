# Red Brand Implementation Plan

**Goal:** 实施用户授权的上下品牌、红色主题和 AI 按钮图标，并将轮播左侧调浅。
**Architecture:** 保留现有页面和轮播数据，通过统一图标组件接入四个图集，修改现有主题和额外品牌排版样式。
**Tech Stack:** React / TypeScript / CSS / 内置 image_gen / Playwright。
**Spec:** docs/plans/2026-11-14-red-community-design.md

## Global Constraints
- 主色 #D8292F；不改变小鱼人物本身的蓝色身份特征。
- 轮播左侧浅珊瑚粉，不能使用深酒红。
- 不将按钮文字烘焙进图片；保留语义、权限、点击和编辑功能。
- 不引入外部字体下载或新的 API；无 Git 仓库，无子代理。

## Review Focus
- 图集行列准确、图标无相邻单元串图，透明背景正确。
- 页头上下品牌在 320/390/768/900/1440px 不溢出。
- 分类图标按名称对应，编辑器 B/I/U、撤销重做等语义准确。
- 主次按钮与小图标在浅底/红底均清晰，焦点和禁用状态可辨。
- 轮播最终素材不是深色初稿，旧蓝色环境不再被引用。
