# 小程序移动端体验优化

- 参照手机网页的浅色背景、品牌红、内容双列卡、讨论列表和资料布局。沿用小程序原生导航和四个底部入口，发布放在对应页面的顶部。
- 将字体、间距、触控反馈、表单、列表和安全区规则集中在 `wechat/miniprogram/app.wxss`。用共用状态组件承载初次加载、加载更多、空结果和可重试失败。
- 逐页覆盖登录与首页、讨论、消息、我的、内容详情、编辑和榜单。保留表单输入、当前筛选和已有列表，以便纠正错误后继续操作。
- 维持现有接口地址、请求体、权限、路由和登录方式。使用项目现有图片和原生控件。
- 检查七个页面编译，通过模拟器验证登录、卡片、导航、表单和详情，使用窄屏和宽屏验证布局。涉及真实发布、评论和已读操作的验证使用隔离数据。
