# 内容审核与独立文件扫描

本文件与 [维护与上线约束](MAINTENANCE.md) 共同记录已确认行为。通过不填原因；内容驳回至少 5 字、文件拦截至少 10 字；贡献资格确认默认不勾选，不能影响普通通过。

## 当前实现与真实边界

当前没有接入任何真实内容审核供应商，也没有配置或验证真实 ClamAV 服务。不能据此声称已自动识别色情、暴力、恐怖极端、违法内容或恶意程序。

- `MODERATION_PROVIDER=none`：需审核账号的新内容与评论进入人工复核；生产默认如此。管理员明确开启账号免审时沿用账号免审流程。
- `development`：只用于开发测试，识别 `[dev:reject]`、`[dev:review]`、`[dev:timeout]` 测试标记。其他文本模拟通过；不是实际审核。production 启动时强制拒绝该配置。
- 管理员的具体短语规则可选择人工复核或直接退回，展示规则名称和解释。匹配先统一大小写和全半角，再忽略空白、标点及不可见格式符；这只是短语匹配，不是完整语义识别。
- 迁移 `011_moderation_presets.sql` 新增 19 条规则：6 条明确辱骂短语直接退回，4 条疑似人身攻击和 9 条暴力、恐怖主义、政变、仇恨相关短语交人工复核。已有规则保留并默认人工复核。直接退回的规则在人工批准时也重新检查，不能提前批准绕过。
- 审核标准对所有国家一致：实际辱骂、人身攻击，以及煽动暴力、恐怖主义、政变和针对群体的仇恨攻击不得通过。正常新闻报道、研究、批评及时政讨论允许发布，不因出现政治词汇而拒绝。需结合全文判断的情况保留人工审核。
- 网站投稿、评论和个人接口投稿使用同一账号审核设置。接口不能指定已批准状态；需审核账号在当前生产环境未配置真实审核供应商时，未命中短语也仍须人工复核。
- 文字覆盖标题、摘要、正文、提示词、所有类型字段、评论、文件名称和提取的文本；审核输入是数据，不会执行其中的指令。
- 图片会解码、限制总计 4000 万像素和最多 100 帧、旋转规范化、缩放到不超过 2000 × 2000 并重编码为 WebP，去掉原有元数据。这不是图像内容审核，也不代替恶意文件扫描。
- 默认允许 PNG/JPEG/WebP/GIF（重编码为 WebP，保留动画）、UTF-8 TXT/MD/JSON/CSV、ZIP、PDF、DOCX/XLSX/PPTX。PDF/Office 尚未完整提取正文及嵌入对象，一律转人工文件复核；不支持用户上传 SVG、旧式 DOC/XLS、视频，未宣称支持 OCR、音视频审核。既有自定义允许类型列表不会被迁移自动扩展。
- ZIP 不落地解压，不执行任何文件；限制 200 项、单项 10 MiB、合计 50 MiB、压缩比 100、提取文本 50 万字符。不安全路径、符号链接、超限、加密、未知二进制或嵌套包均隔离复核。
- ZIP 内可提取 txt/md/json/csv/yaml/ts/js/py/sh/toml 为文本。识别为源代码只表示可读数据，绝不执行。
- 所有资源包和图片独立调用可选 ClamAV INSTREAM；没有服务、扫描失败或解析不完整时保持隔离。开发模拟扫描同样仅为测试。
- 人工通过内容或评论时，同一事务内将其关联的待检查文件一并通过，无需填写原因或另去文件列表操作；已明确阻止或删除的文件不能通过。系统记录“随内容人工审核通过”，不伪装成病毒扫描结果。管理员仍可单独检查文件或导出 `.quarantine`；退回内容和阻止文件需要原因。
- 审核队列支持勾选及全选本页，批量通过或批量退回；接口每批 1–50 个不同任务。逐项核对权限及最新修订，独立提交并返回成功/失败原因；失败项保留选择，任何单项失败都不会放行其关联文件。通过记录默认“人工审核通过”，旧数据和原有规则不变。
- 头像、姓名、简介及站点名称/Logo 属于资料设置，不进入内容审核。站点图片 Logo 仅管理员可上传，验证后立即更新并记录日志，无需人工审核理由；图片解码重编码为不超过 512 × 512 的 WebP，存入数据库配置，读取须登录。存在 ClamAV 连接时额外扫描，异常则不更新；格式验证不代表图像内容识别。

## 贡献资格与内容审核

积分与荣誉已接入统一审核流程。人工通过时可勾选“同时确认贡献资格”，核实案例原创实用或资源完整可用后，按每类每周最多三次、每次 20 分计分。只通过内容不代表确认贡献资格，可随后在“积分与荣誉 → 贡献确认”处理。批量内容审批沿用原发布流程，不默认批量认定贡献。

免审发布保持即时生效，但积分资格需单独确认，包括被采纳的免审回答。正常审核回答由提问者本人采纳后计分；自答与版主代采纳不计分。资格撤回、删除、下架和取消采纳触发原周补位与勋章校验，原积分流水保留。详见 [积分与荣誉](HONORS.md)。

## 接入真实供应商

适配接口在 `server/moderation.ts`：

```ts
interface ModerationProvider {
  name: string;
  review(input: {
    text: string;
    images: { id: string; mime: string }[];
    unparsedFiles: boolean;
    revisionDigest: string;
  }): Promise<{
    decision: 'approved' | 'rejected' | 'review';
    reason: string;
    categories: string[];
  }>;
}
```

接入步骤：

1. 由公司选定供应商、数据处理地区和合同范围。阅读该供应商当时的官方文档，记录支持类别、文字上限、图片格式、语言、计费和保留政策。
2. 在服务端实现适配器，通过依赖注入私有存储读取已校验图片。接口中的图片 ID 不是公共 URL；不得转为永久公开链接。优先使用供应商支持的二进制上传。
3. 所有密钥只放服务端环境变量。生产不能接受浏览器自定义审核服务 URL；避免 SSRF 与密钥泄露。
4. 对文字分块、图片与文件说明分别检查，并汇总覆盖证据。任何类别或素材未被可靠覆盖，应返回 review。明确违规才 rejected，全部覆盖且明确通过才 approved。
5. 如果使用模型，使用结构化输出、可信系统指令与不可信素材分隔；不得把上传文本加入系统指令，不提供执行或联网工具。校验输出枚举与长度；解析异常、超时、限流和网络错误抛出错误。
6. 在 `providerFor` 注册明确名称，增加合同测试和服务异常测试；不能重用开发模拟器。
7. 配置生产环境并重启。后台连接状态仅展示配置事实；`moderation_records` 和任务失败次数反映实际请求结果。

## 队列和修订语义

每个修订/评论有唯一审核任务。数据库 claim 使用事务、行锁与 90 秒租约。处理超时上限 30 秒；失败延后 30 秒重试，连续 3 次失败后进入 failed，由管理人员重试。进程重启后未完成任务或过期租约会继续执行。多进程正式数据库使用 `FOR UPDATE SKIP LOCKED`。

结果验证任务尝试编号、修订摘要和最新修订 ID。过期修订不能替代当前版本。已发布内容编辑时保留原版本；新修订通过后原子切换。部门可见范围立即取当前范围与新范围的交集，扩展部分在通过审核后才生效。

关闭账号、下架或删除不删除历史归属；发现入口与下载权限实时重查。通知先通过内容权限过滤，再计算数量和返回文字。

## ClamAV 说明

实现使用官方 clamd INSTREAM 协议（长度前缀数据块、零长度结束），15 秒超时。服务仅部署在容器内部网络，不公开 3310 端口。示例 Compose 使用可选 scanner profile；建议至少额外 2 GiB 内存，确保病毒库能更新。实际协议和服务配置应依据部署版本的 [ClamAV 官方文档](https://docs.clamav.net/manual/Usage/Scanning.html)。未执行真实 ClamAV 集成验收。

## 账号免审

管理员在成员权限编辑中开启“发布免审”，默认关闭。迁移 `012_account_moderation_exemption.sql` 为所有现有账号保留需审核状态。服务端在每次提交事务中读取当前作者权限；开启后新提交的资源修订、论坛主帖、评论/楼层和个人接口投稿即时发布，不调用内容规则或审核供应商。管理员开关变更与免审发布分别记录审计；复用现有不可变修订、资源版本和通知流程。

关闭后新提交恢复原审核；开关不会批量放行旧待审内容或改变已经发布的版本。资料、头像和 Logo 本来就无需内容审核。部门权限、锁帖、字段校验和文件隔离继续生效；存在未通过安全检查的附件时返回 `review` 并显示文件检查原因，由管理人员处理后再发布。

## 评论图片、表情与附件

评论素材与资源素材分开标记用途。读者只能提交自己在当前内容下上传、尚未绑定的评论文件，每条评论最多 10 个；正文中手写文件地址同样校验。评论图片 ID、附件名称、提取文本及文字一起送入审核。扫描未通过时自动审核不能放行；人工通过评论会同步通过其待检查文件，已明确阻止或删除的文件仍阻止发布。

未提交素材只对上传者可读；待审、退回评论的素材只对该评论作者与授权审核者可读；已审素材仍受原内容权限控制。删除评论后直链不可读。评论附件下载不进入资源下载榜。内置 12 张表情包是项目自有静态 SVG，无外链与用户注入内容；选择后其文字说明进入正文审核。

## 用户头像

头像不进行内容审核，在开发、生产和未配置审核供应商时均直接保存生效。仅允许 PNG/JPEG/WebP，最大 5 MB / 20 MP；实际解码、自动方向后，验证用户选择的方形裁剪坐标并重编码为 256px WebP，移除原始元数据。旧客户端未提交选区时使用中心裁切。已配置 ClamAV 时扫描失败会拒绝保存并保留原头像。

当前头像保存在私有数据库，仅登录成员可读取活跃账号的头像；上传后更新版本，移除后恢复默认头像。头像审核列表、私有待审预览与审核接口已移除。迁移 `007_profile_without_review.sql` 将旧待审图片设为当前版本并清空待审状态，历史审计保留；重复启动不会重复迁移。上传、移除及迁移记录审计，不在日志写入图片内容。帖子、文章等发布内容和评论回复继续执行原有内容审核及素材隔离。
