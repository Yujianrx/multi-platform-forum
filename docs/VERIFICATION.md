## 图片加载与账号免审（2026-11-16）

- 默认横幅、人物、图标图集和按钮改为原图生成的轻量资源，保留原始文件。三张桌面轮播各约 46–59 KB，手机版本约 19–24 KB，登录人物约 85 KB。带内容哈希的文件使用长期不可变缓存；当前轮播优先，下一张延后预载，省流量与慢速连接不预载。
- 对同一现有预览首页、1440×1000 视口、空浏览器缓存，读取加载后约 2.5 秒的 Resource Timing：品牌图片 encodedBodySize 总和从 11,592,029 字节降至 557,086 字节，约减少 95.2%。这是首屏品牌资源传输量对比，未宣称真实公网加载耗时按同比下降。另用浏览器验证刷新复用缓存与手机选择较小图片。
- 私有图片、头像、站点 Logo 提供 ETag；每次使用缓存前仍检查当前登录、部门范围及扫描状态。验证了图片先 200、再 304，以及权限收紧、退出登录、文件被隔离后不能返回 304 或图片正文。
- 成员权限编辑增加默认关闭的“发布免审”，只有管理员能修改。服务端从数据库读取当前状态，普通成员注入字段不能开启；旧客户端更新其他权限不会清除现有免审设置。开关与免审发布记录审计。

### 40 项真实浏览器流程

1. 管理员修改站点名称、上传并移除图片 Logo、编辑并恢复轮播标题。
2. 桌面登录、首页、中文搜索、内容详情、排行榜、后台浏览；捕获页面运行错误，未出现未处理异常。
3. 管理员生成邀请码 → 检查桌面/手机注册提示 → 确认密码不一致时提示 → 6 位纯数字密码注册 → 提示词自动保存 → 预览 → 提交 → 审核发布 → 收藏刷新保持 → 另一成员评论审核后显示。
4. Skill ZIP 真实上传 → 发布 → 另一成员下载 → 浏览器下载成功 → 数据库有效下载数更新。
5. 手机登录、首页、榜单、发布表单、项目详情，以及横向溢出检查。
6. 多账号论坛草稿、附件、发帖、关注、楼层与引用、采纳、只看楼主、通知、版主锁帖与置顶。
7. 四类资源详情均能进入关联发帖页，实际发布后返回资源可见关联话题。
8. 手机论坛版块、搜索、主帖楼层和发帖表单布局及横向溢出检查。

- **没有连接或部署美国服务器，没有正式上线。** 未提供系统、架构、配置、域名或 SSH 信息。
