# 注册说明与资料免审核

用户明确要求邀请注册提示更清楚、密码规则简化，并将内容审核限制为帖子、文章及回复。采用 8–128 位密码，不强制字母数字组合，拒绝全空白；注册、重置和修改密码一致。补充姓名用途、账号格式及不可修改、确认密码、邀请码获取与部门分配说明，保留单列布局。

姓名与简介原本直接保存，继续保持。头像通过既有真实格式/大小/像素检查和重编码后立即生效，与正文审核供应商无关；保留配置的文件安全扫描与登录读取。移除头像人工复核入口、接口及待审提示，迁移既有待审头像为当前版本，历史审计保留。站点名称和管理员 Logo 属于资料设置，也不要求填写内容审核理由。

正文、帖子、评论回复及其内容附件继续原有审核规则，权限、文件隔离和审核记录不改变。测试覆盖短密码边界、单一字符类型、确认密码、注册/重置/修改一致性，生产和未配置审核下头像即时更新、旧头像队列迁移、账号资料不创建审核任务，以及正文审核仍有效。
