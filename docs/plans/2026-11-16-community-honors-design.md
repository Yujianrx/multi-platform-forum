# 论坛积分与荣誉体系（用户已确认）

2026-11-16 用户确认设计及所有待确认口径。沿用 React/TypeScript、Fastify、PostgreSQL/PGlite，不做无关重构。

## 已确认规则
- 案例（experience）、资源（project/skill）、答疑各 +20 分，每人每个北京时间自然周各最多 3 次，共最多 180 分。prompt 暂不计分。
- 原创实用案例及完整可用资源须由管理员或有管理范围的审核人确认资格。内容审核可同时确认；免审内容立即发布，贡献资格另行确认。自动审核发布不等同于人工资格认定。
- 答疑须已通过内容审核、被提问者本人采纳、非自问自答；免审回答需人工确认内容资格。版主代采纳保留功能但不计分。
- 不回补启用前的历史内容。签到、浏览、点赞无积分。同一内容的修订不重复奖励，重复提交及回调幂等；重复内容指纹提示/阻止重复认定。
- 归属首次满足全部条件之周；超额贡献不顺延。失效/删除/下架/撤销采纳撤回积分，并在原周按首次有效时间补位；恢复资格仍归原周。原流水保留，增加负向撤回及恢复记录。
- 等级：0 共创新人、60 实践新秀、180 分享达人、420 共创骨干、900 共创先锋、1800 共创领航者。累计有效积分决定等级，撤回可降级。
- 北京时间周一 00:00（含）至下周一 00:00（不含）；综合、案例、资源、答疑榜，同分同名次（1、1、3）。历史榜结算与更正版本留存。不显示 0 分虚构排名。来源继续判权。
- 六枚勋章：首次案例、首次资源、首次采纳、全能（三类各一次）、持续（历史任意连续四周有效贡献）、优质（管理员人工授予且填写理由）。前五枚依据有效贡献重算；人工依据失效需复核。不因后续断周撤回已达成持续勋章。
- 首页原人气榜换为贡献榜，旧点赞/下载榜保留独立入口。个人积分、等级、明细、勋章墙；作者区紧凑展示；后台规则、资格、流水、人工勋章。

## 数据与一致性
contributions 记录资格与来源，points_ledger 追加式账本，weekly_contribution_buckets 串行化用户周类别额度，leaderboard_periods/entries 留存周榜版本，badge_definitions/awards 记录图片条件和颁发撤回。settings 存版本规则及启用时刻；audit_logs 记管理操作。forum_topics 增采纳人/时间。内容与资格修订绑定；旧版本仍公开时资格保留，新版公开后重新认定。

首版站内文件检查存在/安全状态与可用性；外链由审核人确认可访问且内容匹配，服务器不盲目访问任意投稿 URL。整篇重复及文件指纹用于辅助判重，近似搬运人工判断。权限、部⻔、账号免审、附件隔离不放宽。

## 验收
发分/上限/并发幂等、原周补位、跨周跨年、撤回恢复、停机补结算、并列排名、修订/文件失效、自答/版主代采纳/重复采纳、五类自动勋章复核与人工授勋权限、来源隐私、空状态、桌面手机、既有回归全部覆盖。
