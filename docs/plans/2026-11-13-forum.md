# 论坛扩展

在现有社区加入独立论坛，资源分享和自由讨论并行。采用版块、主题列表、主帖、楼层回复的常规论坛结构，覆盖讨论、提问、反馈和闲聊。首页、导航和所有资源详情均提供讨论入口。

复用分类作为版块；主帖作为 discussion 内容，继续使用持久化修订、审核、附件、举报、权限和后台管理。新增话题元数据、关注和阅读记录。关联资源的话题在每次读取时与原资源访问范围取交集，避免资源收紧权限后泄露讨论。

实施顺序：数据库和权限 → 话题 API、回复与通知 → 论坛列表、发帖与楼层页 → 首页和资源入口 → 权限/业务集成测试、浏览器回归与手机布局 → 更新交付包。

验收重点：审核前不可见、版块与筛选真实查询、引用回复、采纳答案、锁帖、关注通知、附件权限、关联资源权限变更，以及已有资源功能回归。

实施已完成。服务端、前端、三条浏览器论坛流程和十条论坛集成测试均已落地；原有资源功能回归通过。版块复用分类，话题类型存储在独立元数据表，已审内容与待审修订继续分离。交付包含源码、升级说明及桌面/手机论坛预览。
