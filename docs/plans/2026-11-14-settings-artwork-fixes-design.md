# 管理设置与视觉修复

按用户明确指示修复现有设计：复现并修复点击站点设置崩溃；管理后台字体各级增加 1px；消除胶囊底图宽高拉伸；直接以原始小鱼透明 PNG 重新生成三张清晰浅色轮播，并让桌面标题、说明和按钮整体垂直居中。移动端保留文字与人物分区。

按钮问题来自整个图集以百分比缩放到任意长宽，宽按钮将圆角压扁。继续使用原 AI 素材，将单个皮肤视口拆成保持比例的两端与可横向延展的中部；使用 SVG 九宫格等价方案或 CSS 圆角渐变，优先保留原 AI 视觉并修复几何。共享图标亦检查固有比例。

管理请求必须与当前资源 key 对应，不能用上一页响应初始化设置表单。设置表单仅消费完整设置对象；以同一 SPA 内从多个管理页面切换到设置的实际流程回归，而非仅测直接打开 URL。
