按本次明确需求将项目默认名称改为「多端论坛」，GitHub 仓库命名为 `multi-platform-forum`。

- 保留现有三端布局与论坛、资源、账号、审核、积分功能；替换默认标题、LOGO、人物与轮播为不含企业标识的讨论主题素材。

- 更新仓库介绍、Topics、操作文档和 Git remote。保留提交历史，不强推重写历史，不部署现有生产环境。
