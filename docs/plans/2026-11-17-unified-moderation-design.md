# 正文与附件统一审核

用户已要求合并正文、附件审核，并让免审账号的附件同样免审。

- 审核队列及人工审核窗口展示当前提交版本的正文、扩展字段、封面、正文图片及附件。审核人员在同一个窗口预览图片、下载附件，一次通过或退回整个提交。
- 文件管理保留存储查询，移除独立审核入口。保留旧接口兼容性，不改变已有数据。
- 账号免审涵盖文章、帖子、回复和绑定附件；上传及提交均读取数据库中的当前设置。免审来源单独记日志，不冒充病毒扫描结果。
- 已明确阻止、已删除的文件仍不可发布；上传格式、大小、额度、阅读范围仍按原规则。不会批量通过历史待审内容。
- 审核专用文件地址只允许有该任务管理权限的管理员或版主访问精确绑定的文件，不影响公开下载权限或下载统计。
- 沿用现有状态和事务，无数据库迁移。正文与文件操作原子提交，重复审核不重复记录。

验收包括普通账号和免审账号的正文、图片、资源附件与回复；权限撤销；已阻止文件；版主范围；跨任务文件访问；并发和重复审核；桌面及手机审核界面。

用户追加三项手机修复：所有内容卡片等高对齐；首页顶部下拉或连续双击首页刷新；点赞和回复后保留页面与滚动位置。方案为移动卡片统一封面和正文槽位、移动专用刷新容器及共用 API 的后台刷新能力，桌面布局不变。
