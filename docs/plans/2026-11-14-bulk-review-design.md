# 人工审核提效

用户已明确要求：支持批量人工审核，文章通过时关联项目文件默认通过，通过不需填写原因；沿用当前服务器发布流程。本次在现有页面与权限范围内实现，不增加额外确认步骤。

审核队列增加逐项勾选、全选当前页、已选数量、批量通过和批量退回。批量通过直接提交；批量退回填写共用原因。通过内容、评论和独立文件审核均不要求原因，系统留下准确的操作记录；退回继续要求原因。通过内容或评论时，在同一事务内通过其关联的待检查文件，无需另去文件列表操作。明确 blocked 或已删除的文件不能解除，操作返回可读原因；已有辱骂拦截规则仍生效。

可选实现：前端循环调用单条接口简单，但难统一返回部分失败；整批事务会被一篇失败阻断；采用专用批量接口，最多 50 个不同任务，逐条事务和权限检查，返回每条结果。成功项取消选择、失败项保留并显示原因。避免一篇无权、过期修订或已处理的任务阻止其他篇审核。

同步放行文件只作用于本次审核绑定的文件，不影响未绑定或其他内容的文件。先核对任务、当前修订、权限和禁止发布规则；文件状态、内容发布、审核记录、审计在一个事务中，失败全部回滚。不会把人工通过记录成自动病毒扫描通过。自动审核仍遵守原有文件隔离限制。

验证单条无原因通过、批量部分失败、退回原因、权限边界、重复任务、修订过期、已阻止文件及规则失败时的回滚。检查桌面、手机勾选与反馈。先备份生产库及私有文件，发布 v4，无数据库结构迁移，不自动批准生产中的既有待审内容。
