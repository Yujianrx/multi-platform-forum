# 图片加载与账号免审

用户要求提升图片加载速度，并由管理员在账号设置中开启免审。沿用现有 React/Fastify 与统一内容修订流程，保留近期接口投稿、审核规则与批量审核改动。

- 原始品牌素材保留，生成带内容哈希的 WebP、精简按钮 SVG 和轮播小尺寸版本。使用不可变静态缓存，首页当前图片优先，下一张空闲预加载，正文和卡片异步解码。鉴权图片用私有条件缓存，每次重新验证权限后才可返回 304。
- 成员权限设置增加账号免审开关，默认关闭，仅管理员可修改并记录操作日志。状态以服务端数据库为准，成员不能自行开启。启用后新提交的资源、论坛话题、回复和接口投稿同步发布，不执行内容规则或审核供应商；记录免审发布事件。关闭后新提交恢复审核，既有待审不自动批量放行。
- 仍检查发布权限、字段、部门范围和文件安全。需要文件检查时保持隔离并返回真实状态。发布成功时前端跳转已发布内容，不再显示“等待审核”。

验证：素材体积与真实浏览器加载、视觉及缓存；鉴权失效不返回缓存；管理员权限与开关持久化、正常/免审/关闭、帖子及回复即时可见、资源版本与通知、接口投稿一致、附件隔离。
