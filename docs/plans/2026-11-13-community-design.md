# AI 共创社区设计

用户已确定产品方向，并授权常规实现自主选择、按阶段持续实施。本设计直接执行，无额外确认门禁。

采用 React/TypeScript + Fastify 模块化单体。正式部署 PostgreSQL 17，开发使用 PGlite 文件持久化。对比：云端 BaaS 需要额外账户且权限维护跨系统；SQLite 简单但与目标 PostgreSQL 行锁、事务语义不一致。选择同一 PostgreSQL SQL 体系、统一 DB 接口。

界面：暖白背景、珊瑚橙主色、青绿辅助，固定顶栏、主内容与榜单侧栏、手机底部导航；卡片使用原创 CSS 图形封面，不依赖远程图片。主流程为邀请注册、浏览发现、发布编辑、个人空间、管理工作台。

权限每次请求从数据库取得有效账号、部门、管理授权。私有 API 与文件全部 no-store。内容实体维持稳定 ID，修订不可变，当前已发布修订与最新待审核修订分离。可见范围收窄立即作用于内容实体，扩大范围在新修订通过后生效；旧版本另有可见范围交集约束。

审核：规则引擎 + 显式 Provider 接口，开发模拟器禁止用于 production；未配真实服务时人工复核。数据库队列绑定修订 ID 和摘要，租约、重试、重启恢复。文本审核与 ClamAV 文件扫描分开，无法确认安全的附件隔离。原始上传不可执行，图片解码重编码，ZIP 有数量、路径、总展开大小和压缩比限制。

账号使用 scrypt、随机 HttpOnly 会话令牌，数据库只存令牌摘要。所有写入验证 Origin 和 CSRF，注册事务以邀请行锁防止超额，停用和重置撤销会话。

测试重点：并发邀请、部门隔离、修订过期结果、生产安全默认、停用会话、附件与事件去重、重启持久性；真实浏览器完成主要业务流程与桌面/手机布局。
