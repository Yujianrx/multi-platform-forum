# 草稿入口、首页人气榜与编辑保护

用户本轮明确要求修复这三项，沿用现有红色风格、权限和发布审核流程，直接在本对话实施。

- 原因：草稿删除只在个人草稿箱渲染；后台内容列表没有入口。首页仅链接到人气榜。编辑工具栏不吸附，站内导航不触发 beforeunload。
- 删除入口：个人全部内容、草稿箱、编辑页、草稿详情和管理员内容列表按实际修订状态显示。沿用已有删除 API、修订冲突保护和确认；公开文章的新草稿删除保留公开版本。普通用户仅本人，后台仅管理员可删除他人草稿。
- 首页：贡献榜保持独立，另设社区人气榜卡片，点赞、浏览两标签，近 7 天/近 30 天/累计筛选，前 5 名的标题、作者和真实数量，完整榜单入口。无数据给出空状态，不虚构成绩。
- 编辑：推荐导航下方吸附工具栏，避免底部固定栏遮挡编辑器。保存草稿、发布内容随滚动可用；发布内容直接执行现有审核提交；可选预览保留。另一方案仅改按钮文案不解决滚动和误离开问题，因此不采用。
- 离开保护：使用 React Router useBlocker，覆盖导航链接、顶部发布、搜索和浏览器返回；自定义对话框提供继续编辑、保存后离开、直接离开。刷新/关闭页面保留浏览器提示。保存失败停留原页；上传期间禁止离开。成功提交允许离开。
- 无数据库迁移、无新依赖，保留账号、内容、附件、审核设置、积分和榜单规则。回归测试覆盖两种身份、三个删除入口、排序、滚动、离开取消/保存/失败/返回、手机布局、发布及原审核流程。

参考 API：https://reactrouter.com/7.18.5/api/hooks/useBlocker
