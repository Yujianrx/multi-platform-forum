# 所见即所得社区编辑器

用户要求将当前 Markdown 编辑器改成像 Word 一样的所见即所得编辑器，范围包括评论、论坛回复、论坛发帖和四类资源正文。已明确授权实施，沿用前文自主执行约定。

采用 Tiptap 3 的可视化编辑界面，并用官方 Markdown 扩展兼容现有正文、修订和审核。相比直接存储 HTML，此方案不需要迁移历史数据，也不改变服务端附件关联和审核规则；相比自行维护 contenteditable，成熟的文档模型能提供选区、撤销、中文输入和列表操作。核对官方文档并固定依赖版本 3.34.0。

编辑区直接显示图片、表情、标题、粗体、斜体、下划线、删除线、列表、引用、代码和表格。工具栏状态跟随光标，支持键盘快捷键、清除格式、链接编辑、表格行列操作、全屏。无 Markdown 源码输入区或预览切换。保持现有上传、粘贴图片、拖放文件、文件卡片与错误提示。上传期间防止重复操作，异步完成时在当前保存的文档选区插入；不覆盖期间输入。自定义图片和 GIF 继续使用站内文件地址。

历史 GFM 正文（含表格、任务列表、换行、代码块和图片）须可加载和再保存。只有受支持、可以稳定往返的格式提供工具按钮；不引入无法持久保存的字号、颜色或排版按钮。粘贴 HTML 由文档 schema 转换，图片只允许现有文件接口或白名单表情路径；只识别无属性的 u/strong/em/s/del/br 格式标签，不执行脚本和任意 HTML，不加载外部跟踪图片。字符限制沿用服务端序列化长度限制，超限编辑被拒绝并提示。

验证重点：编辑时真实 DOM 格式、光标插入与中文输入、格式撤销、外部粘贴安全、历史内容往返、草稿保存重载、审核发布后的显示一致性、三种评论/发布流程、手机无横向溢出。原后端权限和审核测试继续运行。无 Git 仓库，不创建提交；不部署外部服务。

参考：https://tiptap.dev/docs/editor/markdown/getting-started/basic-usage 、https://tiptap.dev/docs/editor/extensions/nodes/image
