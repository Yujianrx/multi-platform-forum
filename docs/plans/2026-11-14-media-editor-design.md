# 图文评论与统一编辑器

评论、论坛回复、四类资源发布、论坛发帖共用带工具栏的 Markdown 编辑器。保留现有内容存储格式和审核修订架构，避免另一套富文本格式导致历史内容迁移。工具栏提供格式、图片、Emoji/内置图形表情包、附件、预览及全屏。支持粘贴图片、拖放文件、多文件上传、进度、失败提示与移除。

内置表情包使用项目自有 SVG 素材，无第三方追踪或外链；自定义 GIF 经图片重编码保留动画。资源附件支持原有类型，并加入常见 PDF/Office 文档，不能可靠解析的文件继续人工复核。

评论图片与附件使用独立用途标识与关联表。允许读者上传自己的评论素材，不开放原内容编辑权限。提交时校验作者、内容、未绑定状态、文件数量和扫描状态；文字、图片和附件纳入同一审核任务。读取和下载再次检查所属内容、评论状态、删除状态和部门权限。评论附件下载不计入资源下载榜。

保留现有界面与原有权限。用户已授权实现这些交互，沿用前文自主实施约定，不增加审批环节。当前项目无 Git 仓库，不创建无关提交。
