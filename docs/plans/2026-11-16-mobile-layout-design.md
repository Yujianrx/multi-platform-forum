# 手机端独立布局

用户已确认视觉稿及“一套业务功能，分别适配电脑和手机”，要求电脑端保持不变、手机端采用新样式、代码隔离便于维护。

基线为 2026-11-16 v7 源码；从此前开发目录复制到当前项目，排除真实数据库、附件、环境凭据和输出。原开发目录保留不动。当前项目使用 `codex/mobile-layout` 分支。

- 760px 及以下为手机布局；761px 及以上使用原桌面 DOM 和 CSS。断点与既有站点一致。
- `src/mobile/` 持有手机导航、底部发布选择、首页最新/精选/榜单、双列内容卡片、单列讨论列表、个人主页摘要及相关样式。手机样式同时受媒体查询和 `mobile-app`/`m-` 类限制。
- 首页默认最新，类型筛选为全部、经验、项目、技能包、提示词；使用原轮播组件和真实接口，保留分页、分类筛选与空状态。榜单复用贡献周榜，保留点赞/浏览/下载榜入口。
- 底部：首页、讨论、发布、消息、我的。发布打开类型选择，再进入现有编辑器；不复制投稿、保存、附件、审核或登录逻辑。离开编辑仍由既有保护接管。
- 讨论页复用查询参数和 API，保留版块、范围、排序、未回复、采纳状态与关联内容筛选，移动筛选收在面板里。原讨论类型不丢失。
- 个人主页复用当前资料、等级、勋章和内容请求。四个主标签为发布、草稿、收藏、下载；待审、退回、全部、设置、AI 接入和管理入口仍可达。无积分/勋章时展示真实空状态。
- 普通列表卡片仅改变展示；真实封面优先，无封面以实际标题生成文字封面，不写入虚构内容。详情与编辑页面保留业务组件，用独立手机样式适配。
- 不引入新依赖、不迁移数据库、不部署服务器、不修改生产数据。登录、权限、审核、积分、发布、上传与评论仍由现有服务执行。

验证：记录原桌面截图；新增手机端导航/筛选/发布草稿/离开保护/个人标签与勋章测试；320/390/760 和 761/1440 宽度检查；横竖屏切换不丢编辑内容；运行类型检查、生产构建、相关浏览器测试与既有回归。记录代码边界和维护方法。
