# 图片轮播与蓝色社区视觉

用户要求首页改成图片轮播，可直接生图，并按指定阿里云千问 AI 活动页整体复刻社区风格与按钮。已在浏览器查看参考页：高饱和蓝/青/紫渐变、粉色点缀、3D 插画、白色大圆角卡片、蓝紫粉渐变胶囊主按钮和描边次按钮。沿用小鱼号名称、原 LOGO、角色形象与现有论坛业务；不搬入参考页促销价格或品牌内容。

选择完整视觉系统更新，避免只换按钮造成页面不协调；不重建现有功能或引入新框架。首页使用三张 3:1 AI 生成小鱼背景，左侧空白承载可配置的真实文字与跳转，右侧主题插画。已有后台图片优先，否则按资源类型选择默认横幅；无轮播配置时显示三张通用入口。为现有开发示例补充项目轮播，后台可继续修改、排序、停用与定时。

图片轮播独立为 ImageCarousel：上一张、下一张、圆点、暂停/播放、触摸切换、键盘与减少动态效果支持；悬停暂停并在移出后恢复，键盘进入暂停，避免读文字时自动切换。图片失败退回本地横幅。手机上文字在上、主题画面在下，保持完整可读。

全站共享主题更新蓝色背景、文字层次、圆角、按钮、选中/悬停/焦点状态，首页及论坛延续已确认的两栏对齐，详情讨论不跨越正文列。减少重复英文副标签。论坛标题区域与主轮播同一插画视觉，内容列表用白底承载。登录/资料/发布/后台共用按钮样式，权限、文件审核、富文本与头像行为保持。

验证实际轮播切换与暂停、减少动态偏好、后台封面与跳转、三个图像加载、320/390/768/900/1440px 布局与论坛筛选；跑现有端到端回归并检查真实截图。无 Git 仓库，直接在当前工作区实施。用户本轮已明确授权修改与生成图片，不增加确认或子代理。
